FAQ

Common questions.

Does AllianceHQ read normal chat messages?

No. AllianceHQ uses slash commands, buttons and data users deliberately enter into those features.

How are time zones displayed?

Event times are published as Discord timestamps, which Discord renders according to each user's device settings.

Is AllianceHQ already paid?

No. Selected beta servers receive Beta Pro for free. A paid subscription will only be offered after official Discord monetization approval.

How can I delete data?

Use `/privacy export` or `/privacy delete`. Server owners can reset server data. Server data is deleted 30 days after the bot is removed.
